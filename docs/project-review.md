## 优先级建议

**第一优先级**：速度单位切换（#2）、连接名替代接口名（#9）——两项都小且用户直接可感知

**第二优先级**：流量超限通知（#3）、多接口聚合（#4）

**第三优先级**：其余可选增强按需开发；#12 建议作为独立一轮工程改造，不与新功能混做

## 后续维护提示

- 流量统计（`traffic_log.json`）与设置（`settings.ini`）是两个文件，写入路径统一走
  `configFilePath()`；`traffic_log.json` 不可读时会主动禁止写盘（避免覆盖历史），
  不要绕过 `m_trafficLogWriteBlocked` 直接写文件；
- 需要启动子进程的采集（`ss`、`iw`）已改为异步，避免阻塞主线程，新增采集逻辑
  不要再用 `waitForFinished` 同步等待；
- 改写活动接口**必须**走 `applyActiveInterface()`：它负责重置速度基线并清空上一接口的
  派生状态；`calculateSpeed()` 另有基线一致性兜底，直接改写 `m_activeInterface`
  会被识别为"需要重记基线"而丢弃该轮增量；
- 版本号唯一源是 `CMakeLists.txt` 的 `project(VERSION)`，QML/C++ 侧不要写死字面量；
  CI 用 `scripts/check-version.py` 校验它与 CHANGELOG、git tag 是否漂移；
- 新增界面文案后跑 `python3 scripts/check-translations.py` 检查是否漏译；
- 安装路径取自 dde-shell 导出的 `DDE_SHELL_PACKAGE_INSTALL_DIR` /
  `DDE_SHELL_PLUGIN_INSTALL_DIR`，不要在 CMake 里再写绝对路径。
