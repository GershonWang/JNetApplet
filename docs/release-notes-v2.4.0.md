# JNetApplet v2.4.0

> 2026-11-15 · 相对 v2.3.0 共 53 个提交、42 个文件、+6885 / −1292 行

这是一次以**可用性**和**工程质量**为主的版本。新增了多接口聚合、流量提醒与数据导出，补齐了无障碍与 HiDPI 跟随，并把纯逻辑抽成可离线测试的核心库。同时修掉了三个会让插件从任务栏彻底消失的加载错误——本版最大的收获是**建了能自动拦住这类事故的检查链**。

---

## 新功能

### 速度单位可切换

设置窗口新增「速度单位」三档：智能自动（默认）、固定 KB/s、固定 Mbps。

原先只用二进制单位，而运营商套餐与测速工具用十进制 Mbps，两者相差约 8 倍（1 MB/s ≈ 8 Mbps）——拿插件数值与「100 Mbps 宽带」对比时会对不上。

- 任务栏、弹窗、趋势图三处同时生效，趋势图 Y 轴刻度同步换量纲
- 任务栏宽度按当前单位下最长字符串实测，Mbps 档自动放宽，`100.00Mbps` 不会被裁
- 换算规则收敛到 C++ 的 `formatSpeed`，不再由 QML 各处各维护一套阈值

### 显示 WiFi 名称而非接口名

弹窗与任务栏悬停提示改为优先显示 SSID（如 `Home`），取不到时回退接口名。

`wlo1`/`eno1` 由内核按 PCI 位置生成，用户无法据此判断连的是哪个 WiFi。SSID 与链路速率取自**同一次** `iw dev link` 调用，不新增子进程。

### 流量超限提醒

可为日/月各设一个 GB 阈值，超限发一次系统通知。填 0 或留空表示关闭。

- 十进制 GB（1 GB = 1000³ 字节），与运营商套餐口径一致
- 每个周期**只提醒一次**，已提醒的日期持久化，重启 dde-shell 不重复
- 设置窗口回显「今日已用 / 本月已用」，让用户有依据地决定阈值
- 判定逻辑抽为纯函数，阈值边界与跨周期重置全部有单元测试覆盖

### 多接口聚合

设置窗口新增「任务栏显示」：当前接口 / 全部接口。

多网卡场景下只看单卡会低估实际吞吐。聚合与统计都排除虚拟接口（tun/docker/veth/br-/wg 等）——代理的 tun0 流量实际仍走物理网卡，计入会重复计数。

### 导出流量数据

统计窗口顶部新增「导出」按钮，按扩展名写出 CSV 或 JSON。

- CSV 按 **RFC 4180** 转义，数值用纯字节数（便于二次求和，不丢精度）
- 行序与界面一致，避免用户怀疑导出的不是同一份数据
- `FileDialog` 依赖 `xdg-desktop-portal`，精简环境可能弹不出——因此按钮右键可直接导出到下载目录，成功/失败都有浮层提示

### 全键盘与读屏可操作

此前 22 处自绘控件只声明了 `Accessible.role`/`.name`：读屏能朗读，但键盘完全无法操作。

- 新增 `IconButton` 与 `ChoiceButton` 两个公共组件，把无障碍契约收敛到**唯一位置**
- 鼠标、键盘、读屏三条路径转调同一个 `clicked()`，行为不可能不一致
- 焦点可见：获得焦点时描边高亮

### HiDPI 与系统字号跟随

全工程 **112 处** `font.pixelSize` 硬编码（占 7 个文件）收敛为 10 档语义阶梯，随 `Qt.application.font.pixelSize` 缩放。

- 基准值等于改造前的字面量，默认外观零变化
- 缩放下限锁在 1.0：插件已有大量 10~12px 小字，再缩会让图表刻度不可读；放大方向完全跟随
- 任务栏刻意不接入：那里的字号本按 `dockSize` 推导，天然跟随 DPI

## 界面优化

| 项 | 说明 |
|---|---|
| 左键弹窗移除网卡切换 | 只展示设置中选定的网卡。原有两个入口，现在右键管选择、左键管查看 |
| 关于窗口加宽至 400 | 原宽 320 时可用仅 200px，而仓库地址需 218~257px，算数上就放不下 |
| 设置窗口低频分区可折叠 | 「流量提醒」「卸载插件」默认收起，首屏不再一半内容看不见 |
| 图标改用矢量绘制 | 13 处文本字符图标（↓ ↑ ⚠）改为 Shape 组件，消除字形与 emoji 渲染差异 |
| 间距收敛为语义档位 | 此前 `spacing: 12` 与手写 `Item { height: 4 }` 叠加，实际间距是 16 |
| 弹窗底部入口扩大热区 | 触控热区 16px → 24px（无障碍最小值），拉开间距并独立成块 |
| 包统计数字加千分位 | `4275851` → `4,275,851`。刻意不用 `toLocaleString`，避免随系统 locale 变成 `4.275.851` |

## 修复

### 三个「插件从任务栏消失」

都是**一行 QML**，都只在运行时失败，`qmllint` 的语法级过滤全部漏过，现象都是整个插件消失而非某个窗口打不开：

1. `import QtQuick.Dialogs 1.3` —— Qt6 该模块只导出 6.x
2. `ColumnLayout { topPadding: 16 }` —— 布局容器没有 padding 属性
3. `AppletItem { activeFocusOnTab: true }` —— C++ 注册类型未暴露该属性

> 排查方式：`journalctl --user -u dde-shell@DDE | grep -A2 "Loading url failed"` 会直接给出文件名与行号。

### 设置窗口滚动失效

底部「卸载插件」只露出几个像素且滚不出来。

`ScrollView` 会把内容项（`ColumnLayout`）强制拉伸成视口高度，而布局容器的 `implicitHeight` 同样受父项约束——实测 `contentHeight` 609 而内容实际 641、视口 595，滚动余量仅 14px。试过 `height: implicitHeight`（无效）与 `childrenRect.height`（Binding loop），最终改用 `Flickable` 显式绑定 `contentHeight`。

### 切换接口不再产生假增量

活动网卡热拔后后端自动回退到另一块网卡，原实现不重置速度基线，下一轮会拿「新网卡自开机累计 − 旧网卡累计」当增量——两块相差数百 GB，任务栏会显示数百 GB/s，且该假增量被**永久累加**进会话总量与流量日志。

现在用户选择与自动回退统一走 `applyActiveInterface()`，另在采样层加了基线一致性兜底。

### 其他

- **流量日志不可读时不再静默清零历史**：文件不可读时置位写盘禁令，本次会话宁可不记录也不破坏既有历史
- **弹窗接口信息区不再裁切**：双栈无线且链路断开时实际 5 行（约 95px），原固定 76px 会压住下方内容
- **`isPhysicalInterface` 漏判**：原为前缀白名单，板载 `eno1`、虚拟机 `ens33`、USB 有线 `enx*` 全被判为非物理，改用排除法
- **deb 打包依赖预检**：补上遗漏的 `qt6-tools-dev`（CMake 需要它提供 LinguistTools）；`Depends` 按实际 NEEDED 收敛
- **补齐许可证**：补入 LGPL-3.0 全文，deb 内生成 DEP-5 `copyright` 与 `changelog.Debian.gz`

## 工程质量

### 单元测试终于进入 CI

此前主插件依赖 Dtk6/DDEShell，GitHub runner 装不了，导致单元测试**永远进不了 CI**，只能靠真机手工验证。

抽出 `src/core/` 纯逻辑库（解析/判定/日志/格式化），只依赖 Qt6::Core：

- 新增 `JNET_BUILD_PLUGIN` 开关与 `tst_core` 目标，**112 项用例**
- `NetworkMonitorApplet` 的对应方法改为**转调** core，不是复制一份
- 需要文件系统/子进程/DApplet 生命周期的部分刻意不抽（会是假抽象）
- CI 额外断言「用例数非零」，防止 Qt6::Test 缺失时 ctest 报 0 个测试却被当作通过

### QML 运行时契约检查

针对上述三个消失事故，各配一条规则：

| 事故 | 拦截方式 |
|---|---|
| `QtQuick.Dialogs 1.3` | 比对模块 `plugins.qmltypes` 的实际导出主版本 |
| `ColumnLayout.topPadding` | `qmllint` 的 `does not exist` / `Cannot assign to non-existent` 视为失败 |
| `AppletItem.activeFocusOnTab` | dde-shell 注册类型的属性白名单 |

**已用三个历史错误做反向验证**：逐一注入均被拦截，还原后通过。这不是摆设。

### 其他

- 版本一致性脚本区分「仓库无标签」与「git 不可用」（后者此前静默按通过）
- 单元测试隔离真实用户配置，不再触碰 `~/.config/jnetapplet/`

## 升级说明

```sh
git pull
bash install.sh          # 或 bash build-deb.sh && sudo dpkg -i jnetapplet_2.4.0_amd64.deb
```

需重启 `dde-shell`（安装脚本会自动处理）。

### 需要注意的口径变化

- **「今日已用」会比以前大**：流量统计现在计入所有物理网卡，原只算活动接口
- **纯 VPN 场景不计入**：流量只走 tun 时不会统计（tun 属虚拟接口，计入会与物理网卡重复）
- **左键弹窗不再能切网卡**：请用右键设置窗口

### 已知限制

- `traffic_log.json` 的累计仍只覆盖物理接口，VPN/容器流量不记录
- 设置窗口内容较长时仍需滚动（折叠已缓解，但未一屏放满）
